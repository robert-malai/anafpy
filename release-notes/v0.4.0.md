# anafpy 0.4.0 — tax declarations (declarații)

## Highlights

**Tax declarations (`anafpy.declaratii`)** — a new strand of the library: author, validate, sign, file, and track Romanian tax-declaration forms.

- **Local authoring & validation** via ANAF's own DUKIntegrator (headless): `declaratie_validate` runs the per-form official validator jars — ANAF stays the validation authority, anafpy never re-implements form rules — and `declaratie_render` produces the official smart PDF. Per-form generic: works across all 173 DUK-filable forms.
- **Qualified signing with no key material in-process**: `sign_pdf` (pyHanko, `adbe.pkcs7.detached` incremental update) delegates the raw signature to the OS token via `KeychainRawSigner` (Security.framework) — the PIN/2FA stays a human gate and never enters the process. macOS-only for now; the `RawSigner` protocol is the Windows seam. New extra: `anafpy[declaratii]`.
- **Payment-evidence numbers** (`nr_evid`): pure composers of the 23-char number for the self-assessed forms — D300, D100/D710, D101, D301.
- **Filing status & receipts** over ANAF's public, no-auth StareD112 service: `DeclarationStatusClient` reports a filed declaration's processing state and downloads the signed recipisa (upload index + CUI are the access key) — no login of any kind required.
- **Portal upload** (`DeclarationUploadClient`): certificate login + multipart filing against the `decl.anaf.mfinante.gov.ro` WAS6DUS portal — live-verified by filing a **D406T**, ANAF's sanctioned no-fiscal-effect SAF-T test declaration. Rejection pages come back as typed business outcomes, never exceptions.
- New CLI: `anafpy declaratii validate | render | sign | status | recipisa`.

**MCP server additions** — the declaration pipeline as tools: `declaratie_validate`, `declaratie_render`, a `confirm`-gated `declaratie_sign` (no MCP tool ever accepts a PIN), `declaratie_nr_evid`, `declaratie_duk_status`, and the login-free `declaratie_status` / `declaratie_recipisa`. Configured with `ANAFPY_DUK_DIR` (+ optional `ANAFPY_DUK_JAVA`, `ANAFPY_SIGN_IDENTITY`).

**Declaration form reference** — `docs/anaf-reference/declaratii/`: the DUK and StareD112 wire references, plus a form inventory of all 173 filable forms bucketed by SME usage, with hands-on completion guides (purpose, who-files-and-when, row-by-row filling maps, DUK-validated examples, researched gotchas) for the most common declarations.

**Claude plugins** — the repo now publishes a plugin marketplace (`/plugin marketplace add robert-malai/anafpy`) with two plugins: `anafpy-setup` (assisted install + Claude connector configuration on an end user's computer) and `anafpy-workflows` — the workflow skills' single home (including the new `declaratie-prepare` playbook), surfacing in Claude Cowork as Agent Skills and re-served by the MCP server as prompts.

### Breaking

- `ANAFPY_SPV_CURL` was renamed **`ANAFPY_CURL`** (no compat alias): the override now covers both certificate bootstraps — SPV and the declaration upload portal.

### Also

- `Environment` is re-exported from the top-level `anafpy` package (it appears in public client signatures).
- TLS minimum-version floor on all clients; CI token permissions hardened.

Install: `pip install 'anafpy[mcp]'`
