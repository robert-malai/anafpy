# e-Transport API

The client, its value types, the bidirectional flat models, and the UIT
presentation layer (the card model, the validity rule, the PDF renderer and the
nomenclature labels it shares with the MCP server). The generated
XSD models (`anafpy.etransport.schema`) are intentionally not documented here —
their nomenclature enums (`CodJudetType`, `CodTaraType`, …) mirror ANAF's code
lists one-to-one.
